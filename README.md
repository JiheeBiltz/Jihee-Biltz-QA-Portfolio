## Before Running Tests

1. Test Scope

This project is a sample test focused on representative features to demonstrate the testing approach, rather than comprehensive coverage of all possible scenarios.

2. Assumed Requirements

As formal requirements were not provided and some areas were ambiguous, assumed requirements were defined and applied as a basis for testing.

3. Testing Environment Limitations

Testing was performed on a personal computer rather than a clean or dedicated test environment. Therefore, local browser and system configurations may have affected test execution. Environment-specific issues were considered separately from application defects.

   ** Test Environment

   - OS: Windows 11
   - Browser: Google Chrome 153
   - Programming Language: Java 18
   - Automation Tool: Selenium WebDriver 4.48.0
   - Test Framework: JUnit 5
   - Application: SauceDemo
